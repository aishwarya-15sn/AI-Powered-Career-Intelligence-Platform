# 🎯 Placify – Career Intelligence Platform

Placify is an AI-driven Career Intelligence Platform developed as a final-year project to help students understand their career readiness and make informed career decisions.

## 🚀 Review-I Working Prototype

The current Review-I prototype focuses on:

- 👤 Career Profile
- 📄 Resume Analysis
- 🧠 ESCO Skill Intelligence
- 🎯 Target Role Analysis
- 📚 Learning Recommendations

## 🔄 Placify Journey

1. Build Career Profile
2. Upload Resume
3. Extract Resume Skills
4. Select Target Role
5. Analyse Skill Gaps
6. Get Learning Recommendations

## 🧠 Core Technologies

- Python
- Streamlit
- SQLite
- Pandas
- NumPy
- Scikit-learn
- ESCO Occupational and Skills Data
- PDF Resume Processing

## 📊 Data

The project includes structured datasets for:

- ESCO occupations
- ESCO skills
- Occupation-skill relationships
- Job descriptions
- Learning resources
- Interview questions
- Technical questions
- Aptitude preparation
